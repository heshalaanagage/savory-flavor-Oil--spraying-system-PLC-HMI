# Savory Flavor Spraying System Automation

## Project Overview
This project contains the design and simulation of an automated savory flavor spraying system developed for snack/biscuit seasoning applications. The system was designed to mix oil with savory flavoring and spray the mixture onto biscuits in a controlled process environment.

The automation system was programmed using Mitsubishi PLCs in GX Works, while the HMI interface was developed using Kinco DTools software.

> Note: This project was simulated and tested virtually and was not implemented in a real industrial environment.

## System Functions
- Oil and savory flavor mixing process
- Automated flavor spraying control
- Process monitoring through HMI
- Adjustable recipe/timer settings
- Alarm and fault monitoring
- Emergency stop system
- Overload protection logic
- Auto restart functionality
- Process status indication
